# 작업 메모 → 인수인계 보고서 변환 프로그램 설계

## 목적과 이유

생산 현장 교대 시 남기는 짧은 작업 메모를, **다음 근무자**가 "무엇이 조치됐고 무엇이 아직 확인되지 않았는지"를 바로 구분할 수 있는 인수인계 보고서로 정리한다. (출처: `실습_1.docx`)

핵심 위험은 요약 과정의 **과장과 날조**다. 다음 근무자는 보고서를 믿고 확인을 건너뛸 수 있으므로, "20개 확인했는데 정상"이 "문제 해결됨"으로 바뀌거나, 메모에 없는 라벨 여분 수량이 숫자로 채워지면 보고서가 오히려 해롭다.

## 목표

1. 사용자가 메모를 입력하면 Claude API로 내용을 정리한다.
2. 보고서는 **발생한 일 / 조치한 내용 / 현재 상태 / 다음 근무자 확인 사항** 4개 항목으로 나눈다.
3. 확인하지 못한 원인·수량·시각 등은 **"미확인"**으로 표시한다.
4. 결과를 **화면에 출력**하고 **텍스트 파일로 저장**한다.
5. 설치와 실행 방법을 `README.md`로 제공한다.

## 비목표

- GUI/웹 화면, 데이터베이스, 보고서 이력 관리
- 메모 내용에 대한 원인 추정·해결책 제안 (보고서는 기록 정리이지 진단이 아니다)
- 여러 메모를 하나의 보고서로 합치기 (메모 1개 → 보고서 1개)

## 실패로 간주하는 것 (안티 목표)

- 원문에 없는 사실, 원인, 수량, 시각, 담당자 이름이 보고서에 나타남
- 부분 확인("20개 정상", "6개 대조 일치")이 전체 해결/완료로 일반화됨
- 미확정 정보("4시쯤, 확정 아님", "전화로만 전달받음")가 확정 사실처럼 서술됨
- 확인 범위를 넘어선 추론(예: "인수 확인" → "출하 완료")

## 제약

- Python 3.12 (설치되어 있음), 공식 `anthropic` Python SDK 사용
- Windows 11 + PowerShell 환경에서 한글이 깨지지 않아야 함 (입출력 UTF-8)
- API 키는 환경변수 `ANTHROPIC_API_KEY`로 받음 (코드나 파일에 키를 쓰지 않음)
- 테스트 자료: `참고/작업메모_01~20.txt` (UTF-8)

## 결정된 방식

*(사용자가 직접 정한 항목은 없음. 아래는 모두 Claude의 판단이며 검토 대상)*

- **모델:** `claude-opus-5-5`, effort `medium`. 서버 측 거절 대비 `fallbacks: "default"`를 켬. — Claude의 판단
- **응답 형식:** 구조화된 출력(Pydantic 스키마)으로 받아 프로그램이 고정 양식 텍스트로 렌더링. 각 항목에 **원문 근거 문장(source_quote)**을 함께 받음. — Claude의 판단
- **자동 점검(경고만, 차단 안 함):** — Claude의 판단
  - 보고서 문장에 나온 숫자/시각이 원문에 없으면 경고
  - 근거 문장이 원문에 실제로 없으면 경고
  - 원문에 없는 "해결/완료/정상화/이상 없음" 계열 단어가 보고서에 나오면 경고
- **입력:** 터미널 붙여넣기(기본), `--file 경로`, `--dir 폴더`(폴더 안 .txt 각각 처리). — Claude의 판단
- **저장:** `reports/인수인계_<원본이름>_<YYYYMMDD_HHMMSS>.txt`, 원문 메모를 보고서 끝에 함께 첨부. — Claude의 판단

## 보고서 양식

```
==============================
 교대 인수인계 보고서
 작성: 2026-10-15 14:30 / 원문: 작업메모_01_라벨이상.txt
==============================
■ 발생한 일
- 08:40 포장 2호기 라벨이 반복적으로 비뚤어짐
■ 조치한 내용
- 09:10 센서 주변 청소 후 재가동
- 재가동 후 20개 확인 결과 정상 (20개에 한한 확인)
■ 현재 상태
- 원인은 확인되지 않음
■ 다음 근무자 확인 사항
- 오후조에서 라벨 상태 재확인
- 라벨 여분 수량 확인
■ 미확인 사항
- 라벨 비뚤어짐 원인: 미확인
- 라벨 여분 수량: 미확인 (메모에 "얼마 안 남음"만 기록)
------------------------------
※ 자동 점검: 이상 없음
------------------------------
[원문 메모]
...
```

항목이 비면 `- 메모에 기록 없음`으로 출력한다.
